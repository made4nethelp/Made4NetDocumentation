### ViewToTable Scheduler

A new **configuration-only scheduler** has been added that allows inserting data from a SQL **View** into a SQL **Table** without writing any new scheduler code.

**Key highlights:**
- Fully reusable scheduler implementation
- View and table are configurable via scheduler arguments
- Supports multiple use cases using the same scheduler
- No code changes required for new implementations

Refer to:
- **Schedulers → ViewToTable Scheduler** for full setup and configuration details
