## Release Notes 4.12.1.7

**Release Date:** March 4, 2025  

### Description

1. When multiple users accessed Workstation screens with custom views simultaneously, the system cache got clogged, requiring the IIS of the SCExpert server to be reset.  
Now the cache mechanism has been enhanced to support a larger number of users accessing custom-view screens simultaneously.  

2. During Parallel Pick, if the Material Handling Equipment was not able to reach the task’s destination location, the delivery screen showed without data.  
Now, when the Material Handling Equipment cannot reach the destination location during Parallel Picking, it will be successfully redirected to the Handoff location.  

3. When loads were merged, the merge did not include the Edit Date and Edit User of the “Incoming” load.  
Now, when an incoming load is merged both the Edit Date and Edit User fields are updated.  

4. When a Receipt included Receipt Lines for different Clients, the Receipt appeared multiple times on the Receipt screen.  
Now, Receipts with Receipt Lines with different Clients are displayed once on the Receipt screen.  
Workstation → Warehouse → Inbound Process → Receipts (RE)  

5. Staging Flow Through loads was not possible.  
Now, when performing Staging to Flow Through loads, the Flow Through Order and its loads update to status Staged.  
RDT → Picking → Staging  

6. No event was issued by the system when the Shipment status changed to Loaded.  
Now, the Shipment Loaded event (Event #61) is issued and is written to Audit.  

7. Users assigned to the Unloading task were incorrectly directed to the Unload From Shipment screen (UnloadShipment.aspx).  
Now, users are correctly redirected to the Unloading (UNLOADING.aspx) screen.  
RDT → Task → Unloading  

8. When receiving the full quantity of an Inbound Order line, the user was prompted to re-enter the location where inventory is received, even if not all Inbound Order lines were received.  
Now, the user can receive inventory from multiple Inbound Order lines without needing to re-enter the location.  
RDT → Inbound → Receive By Order  

9. It was not possible to use the Export Grid Data on any of the Customer Access screens.  
Now, Export Grid Data works on all Customer Access screens.  

10. When the Client Picking Policy Strategy Auto Release was set to 'Do Not Release', and the Wave Assign Policy Plan Method was set to 'Plan & Release', the system created Picklists but did NOT release them.  
Now, if the Wave Assign Policy Plan Method is set to 'Plan & Release', the system will create the Picklists and release them.  

11. Picklist Activity History tab shows duplicate records of the same activity.  
Now, Picklist Activity History tab does not show duplicate records.  

12. When a user added a Task Assignment Policy Detail with Task Type Parallel Pick, it was displayed as Partial Pick.  
Now, when adding a Task Assignment Policy Detail with Task Type Parallel Pick, it is correctly displayed as Parallel Pick.  

13. TaskSubType field allowed up to 10 characters.  
Now, TaskSubType field allows up to 20 characters.  

14. Remote Printing failed to print labels when the content contains non-UTF (non-Unicode) characters.  
Now, Remote Printing supports non-UTF characters.
