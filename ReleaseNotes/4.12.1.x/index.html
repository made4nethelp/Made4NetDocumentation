4.12.1.x Release Notes & Hotfixes

Release Notes 4.12.1.28

Description

  1. In some cases, when using the Create & Pickup option in the Create Load flow, the system did not navigate the user to the Putaway or Replenishment task.
  2. Now, when using the Create & Pickup option, the system correctly directs the user to either the Replenishment or Putaway task, as applicable

Appendix

Replace the following files in the RDT/bin folder WMS.MobileWebApp.dll WMS.WebCtrls.dll Made4Net.Mobile.dll Made4Net.WebControls.dll

Description

Appendix

Release Notes 4.12.1.26

Description

  1. Previously, when a user without an assigned default Warehouse Printer attempted to print a Label, the system routed the print job to the default SKU Label printer. Now, when printing Labels from the Workstation screens and no user default Warehouse Printer is assigned, the system correctly selects the default printer based on the specific Label type

Description 1. Images added during the Proof of Delivery step were not always uploaded successfully. The image upload mechanism has now been improved to better handle unstable or slow internet connections, ensuring more reliable uploads. 2. Release Notes 4.12.1.3

Description

  1. When a load was created with a UOM other than the lowest UOM, the system created the load with the wrong quantity. Now, the system creates loads with the correct quantity based on the SKU UOM. Workstation → Warehouse → Inbound Process → Create Loads (CA) RDT → Receiving → Create Load

  2. When the Allocate UOM Qty field was defined in the Picking Policy line, the system allocated inventory even though the UOM did not exist in the SKU. Now, the system will allocate inventory ONLY if the UOM defined in the Allocate UOM Qty field is also defined in the SKU.

  3. The TaskSubType dropdown field in Task Assignment Policy did not show values. Now, the TaskSubType dropdown field shows values according to the values set in the Code Table. Workstation → Setup → Policies Setup → Task Assignment Policies (TP)

  4. The TaskSubType dropdown field in Tasks did not show values. Now, the TaskSubType dropdown field shows values according to the values set in the Code Table. Workstation → Warehouse → Task Management → Tasks (TS)

  5. The TaskSubType dropdown field in the Picking Policy Release tab did not show values. Now, the TaskSubType dropdown field shows values according to the values set in the Code Table. Workstation → Setup → Policies Setup → Picking Policies (PS)

  6. The Default Receiving UOM dropdown field in SKU Inventory Edit mode did not show any values. Now, the Default Receiving UOM dropdown field shows values set in the SKU UOM tab. Workstation → Masterdata → SKUs (ST)

  7. It was not possible to edit the values in the Document Attachment Format dropdown field of the Attachment tabs. Now the values of the Document Attachment Format dropdown field can be edited via the Code Table. Workstation → Setup → Warehouse Administration → Code Table (CT)

  8. There were missing Events and Audit entries in the Warehouse Upgrade script. For the full list of Events refer to Table 1 below.

  9. There were missing English vocabulary entries in the SYS Upgrade script.

Release Notes 4.12.1.1

Description

  1. When a message was sent to a group of mobile users, and the message was read by one of them, the other users did not receive the message. Now the RDT messages show for all users. Workstation → Warehouse Activity → Mobile Users Messages (MUM)
  2. The RDT message box did not support line breaks in Right To Left (RTL) languages. Now line breaks are supported in all RTL languages.
  3. Not all the RDT’s Mobile User Message box elements were translatable. Now all message box elements are translatable.
  4. Additional security measures were applied to the Print Client Token screen. Workstation → Setup→ Printers and Labels → Print Client Token (PCT)
  5. The Local Print Client was not able to connect to the SCExpert server after the Print Client Token was refreshed. Now the client connects successfully after the Token is refreshed.
  6. The Counter screen opened with no display. Now the Counters screen opens successfully. Workstation → Setup→ Warehouse Administration → Counters (CTR)
  7. The Counter Value field was mistakenly labeled Counter Interval. Now the field is labeled Counter Value. Workstation → Setup→ Warehouse Administration → Counters (CTR)
  8. The Multi Warehouse Queue flag is not showing in the insert mode of Message Queues tab. Now the Multi Warehouse Queue flag shows in the insert mode
  9. It was not possible to add attachments in the Attachment tab of the various screens when the Workstation was set to RTL languages. Now it is possible to add attachments when the Workstation is set to RTL languages.
  10. It was not possible to add a SKU image in the SKU General tab when the Workstation was set to RTL languages. Now it is possible to add SKU image when the Workstation is set to RTL languages. Workstation → Masterdata→ SKUs (ST)
  11. The Signature link did not open the confirmation image. Now, the image opens in a new tab when clicking the link. Workstation → Delivery→ Route Tasks (RA)
  12. Various changes to the application infrastructure. Delivery Expert React Application
  13. Added the business objects ValueAdded Orders and Assembly Orders. WebAPI
  14. The Order Automation Activities Assign Outbound Order to Wave and Assign Outbound Order to Shipment were not written properly to Audit, causing the service to get stuck. Now, the Assign Outbound Order to Wave and Assign Outbound Order to Shipment activities do not cause the Audit service to get stuck.
  15. The system had a limit on the size of the TransactionData stored as part of the Connect Transaction. Now the limit is removed.
  16. When a Scheduler Application was created or edited, the Application Trigger definitions were not set properly. Therefore, the Scheduler Application did not invoke in its’ scheduled time. Now, the Scheduler Applications invoke successfully.
  17. It was not possible to receive Load Putaway tasks using the RDT. Now, users can receive a Load Putaway task.
  18. The SCExpert Connect Import service failed to start after an upgrade of the system.
